## 📋 Visão Geral

**Brfing** é um sistema de briefing para projetos web que permite que agências criem briefings estruturados e clientes preencham via link único, sem necessidade de cadastro.

## ✨ Funcionalidades

- 📋 **Briefings Estruturados**: Criação de projetos com seções pré-definidas (logo, empresa, serviços, cores, etc.)
- 🔗 **Links Únicos**: Cada cliente recebe um link exclusivo com token de acesso
- 📤 **Upload de Arquivos**: Clientes podem enviar imagens, logotipos e referências
- 📊 **Controle de Progresso**: Acompanhamento visual de seções concluídas
- 🗄️ **Persistência SQLite**: Banco de dados leve e sem necessidade de configuração

## 🛠️ Stack Tecnológica

| Categoria | Tecnologia |
|-----------|------------|
| Backend | Express (Node.js) |
| Banco | SQLite (better-sqlite3) |
| Upload | Multer |
| Frontend | JavaScript (vanilla) |
